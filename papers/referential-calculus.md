# Referential Calculus: The Unified Framework

## The Core Insight

Every instance explored in this project — certified reals, boundary evolution, chirality, shadow→sun, quantum uncertainty, camera optics — is the same μF/νF skeleton:

- a **finite reference** (what you observe/control)
- a **lossy projection** (the forward map)
- an **infinite referent** (what's really there)
- a **conjugate-pair tradeoff** (what you can't have both of)
- a **certified invariant** (the fixed point / limit)
- a **bridge** (the theorem that makes convergence honest)

## The Six Instances

| Instance | Reference (μF) | Referent (νF) | Conjugate Pair | Fixed Point / Invariant | Bridge (Certificate) |
|---|---|---|---|---|---|
| Certified Reals | digit stream | the real | precision ↔ range | the real number | Cauchy condition |
| Boundary Evolution | update rule | shape trajectory | filter ↔ data | converged shape O* | energy decrease |
| Chirality | two-channel + θ | analytic structure | even ↔ odd | κ = √(θ(2-θ)) | the identity itself |
| Shadow → Sun | cube + shadow | the light | direction ↔ distance | sun direction/position | least-squares solve |
| Quantum | one measurement | wavefunction | position ↔ momentum | the state | Δx·Δp ≥ ℏ/2 |
| Camera | aperture | the image | width ↔ depth | the focused image | space-bandwidth product |
